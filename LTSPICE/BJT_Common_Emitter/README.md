# BJT Common-Emitter Amplifier

BJT Common-Emitter amplifier simulated using LTspice.

- VCC: 12 V
- Input: 10 mV, 1 kHz
- Transistor: NPN
- Voltage Gain: ≈ -90
- Output: Amplified and 180° phase shifted
